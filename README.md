# Kristu Mu Nyimbo 🎵📖
### Seventh-day Adventist Hymnal in Bemba (Zambia)

**Kristu Mu Nyimbo** is a simple, beautiful, and completely offline digital hymnal for the Seventh-day Adventist Church in Zambia and Bemba-speaking communities worldwide.

---

## ✨ Features

- **Official Adventist Logo:** Opens with the official Seventh-day Adventist Church emblem and golden warm background.
- **Complete Bemba Hymnal:** All traditional hymns with complete stanzas, choruses, author details, and scripture references.
- **Works 100% Offline:** No internet connection needed after installation. Perfect for church sanctuaries, camp meetings, and rural areas.
- **Fast Search:** Find any song instantly by hymn number, title, or any Bemba lyric phrase.
- **Number Dialpad:** Type a number (like `7` or `125`) and press Go to open the hymn right away.
- **Tune Melody Player:** Listen to synthesized piano melodies to practice tunes and learn new hymns for choir and Sabbath School.
- **Thematic Topics:** Browse hymns grouped by worship themes like the Sabbath (*Sabata*), Second Coming (*Ukubwela kwa kwa Kristu*), Praise & Prayer (*Lulumbi na Kupepa*), and Grace (*Uluse lwa kwa Lesa*).
- **Favorites & Service Planner:** Save your favorite hymns and build an order of service for Sabbath morning worship, AY, or choir rehearsals.
- **Comfortable Reading & Typography:**
  - **Text Size:** Standard (16px), Large (19px), Extra Large (23px), or Senior / Elder (28px).
  - **Line Spacing:** 1.5x (Normal), 1.85x (Relaxed), or 2.3x (Loose) for easy reading on all screens.
  - **Font Choice:** Traditional Lora Serif or Modern Clean Sans.
  - **Themes:** Warm Parchment (Light) or Night Sanctuary (Dark).
  - **Auto-Scroll & Keep Awake:** Smooth hands-free scrolling and screen wake lock while singing.
- **Send Feedback & Rate:** Rate the app with 5 stars, leave comments, and report hymn typos or tune corrections directly in Settings.
- **Share & Support Us:** Share the hymnal via WhatsApp, copy links, or support the ministry with prayer, proofreading, and contributions.

## 📱 How to Install on Your Phone or Tablet

This app is a Progressive Web App (PWA). You can install it on any smartphone, tablet, or computer:

### Android (Chrome)
1. Open the app link in Google Chrome.
2. Tap the **Install App** button on the screen (or tap the 3 dots menu at the top right).
3. Select **Add to Home screen** or **Install**.
4. The hymnbook icon will appear on your phone screen like a normal mobile app.

### iPhone / iPad (Safari)
1. Open the app link in Safari.
2. Tap the **Share** button (the square with an arrow pointing up at the bottom).
3. Scroll down and tap **Add to Home Screen**.
4. Tap **Add** at the top right.

## 🛠️ Technology Used

- **React 19 & TypeScript:** Fast, reliable user interface.
- **Tailwind CSS:** Clean, warm design crafted for church worship.
- **Vite:** Rapid development and lightweight build.
- **Web Audio API:** Real-time synthesized melody player for hymn tunes.
- **IndexedDB & LocalStorage:** Safe offline storage for favorites, service lists, and preferences.

## 🚀 Running the Project Locally

If you are a developer and want to run this app on your computer:

1. Clone or download the project files.
2. Open your terminal in the project folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and go to:
   ```
   http://localhost:3000
   ```

To build the project for production:
```bash
npm run build
```
